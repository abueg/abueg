### taxonomy
- common name: linelle
- binomial name: *Linunculus noveboracensis*
    - *[-unculus](https://en.wiktionary.org/wiki/-unculus)* → diminutive
    - *noveboracensis* → from *[Novum Eboracum](https://en.wiktionary.org/wiki/Novum_Eboracum)*, new latin for new york + *[-ensis](https://en.wiktionary.org/wiki/-ensis)*, meaning 'of or from a place'
